# Camp Lium 🌲

> 자연이 쉬어가는 곳 — 숲과 호수, 별빛 아래의 하루.

<br> 숲·호수·별빛의 결에서 출발한 **가상의 아웃도어 캠핑 브랜드 사이트**입니다. 브랜드 소개와 캠프 스타일·즐길거리 아카이브부터 **상세 페이지 → 예약 → 문의**로 이어지는 이용 흐름까지, 종이·수채 감성으로 담은 반응형 웹 사이트입니다.
<br>

<br> 🔗 **데모**
- GitHub Pages: `https://<본인계정>.github.io/camplium/`  *(배포 후 주소로 교체)*

## ✨ 주요 기능

- **메인 히어로 & 섹션** — 수채 일러스트 히어로, 캠프 소개 · 캠프 스타일 · 즐길거리 · 이용 안내 · 소식 & 리뷰 섹션. 종이 질감 배경과 **손으로 찢은 종이(torn paper) 섹션 전환**으로 이어지는 몰입형 구성
- **캠프 스타일** — 오토 캠핑 · 글램핑 · 백패킹 · 캠핑 데크 4종. 각 **상세 페이지**(소개 · 특징 · 이용 정보 · 추천 대상 · 예약 CTA)
- **즐길거리(Activities)** — 호수 카누 · 숲길 트레킹 · 캠프파이어 · 별빛 관찰. **지도 위 핀 클릭 → 상세 이동**, 전체 목록 페이지 제공
- **소식 & 리뷰** — 공지 · 스토리 · 리뷰 3종의 **기사형 상세 페이지**
- **캠프 예약** — 캠핑 스타일 선택 · 체크인/아웃 · 인원(성인·어린이) · 예약자 정보 · 요청사항 입력, **실시간 예상 금액 계산**(박 수 × 스타일 요금), 유효성 검사, **신청 확인 화면**
- **문의하기** — 연락처(전화 · 카카오톡 · 이메일) · 오시는 길 · 운영 시간 카드 + **문의 폼**(유형 선택 · 유효성 검사 · 접수 확인)
- **완전 반응형** — 모바일 햄버거 드로어 메뉴 · Grid/Flexbox 레이아웃 · 카드 호버 인터랙션 (가로 스크롤 0)
- **self-hosted 웹폰트** — 폰트를 프로젝트에 직접 포함해 **새로고침 시 글꼴 깜빡임(FOUT) 없음**
- **WebP 이미지 최적화** — 원본 대비 약 88% 용량 절감

## 🛠 기술 스택

- **Frontend** — HTML / CSS / JavaScript (빌드 도구 없는 정적 사이트)
- **인터랙션** — Vanilla JS (모바일 메뉴 토글 · 예약 폼 금액 계산·검증 · 문의 폼 · 지도 핀 이동)
- **웹폰트** — self-hosted(woff/woff2): **Pretendard**(본문) · **고운바탕 Gowun Batang**(제목 명조) · **Caveat**(영문 스크립트)
- **이미지** — 전 페이지 **WebP 최적화**
- **호스팅** — GitHub Pages (정적 사이트)

> 스타일은 `styles.css` 상단의 **디자인 토큰(CSS 변수: 색 · 폰트 · 굵기 · radius)** 을 단일 소스로 관리합니다. 톤을 바꾸려면 이 변수들만 수정하면 전 페이지에 반영됩니다. 서브·상세 페이지 전용 스타일은 `detail.css`에 분리돼 있습니다.

## 🚀 실행 방법

### 로컬 서버로 보기 (권장)
```bash
# 둘 중 아무거나
python -m http.server 8000        # → http://localhost:8000
# 또는 VS Code의 "Live Server" 확장 사용
```
> `file://`(더블클릭)에서도 대부분 동작하지만, 웹폰트·이미지 등 일부는 로컬 서버에서 더 안정적입니다.

> 💡 CSS는 캐시 무효화를 위해 `?v=YYYYMMDD` 쿼리를 붙여 로드합니다. `styles.css`·`detail.css`를 수정하면 모든 HTML의 버전 문자열(`?v=`)을 함께 올려야 재방문자에게 최신본이 반영됩니다.

## 🌐 배포 (GitHub Pages)

정적 사이트라 GitHub Pages로 바로 배포할 수 있습니다.

1. 이 폴더(`index.html`이 최상단이 되도록)를 GitHub 저장소에 푸시
2. **Settings → Pages → Build and deployment**
3. Source를 **Deploy from a branch**, 브랜치를 `main` / 루트(`/`)로 지정
4. 발급된 URL로 접속

```
camplium/                          # 사이트 루트
├── index.html                     # 메인 (히어로 · 소개 · 캠프 스타일 · 즐길거리 · 이용 안내 · 소식&리뷰)
├── reserve.html                   # 캠프 예약 (예약 폼 · 실시간 금액)
├── contact.html                   # 문의하기 (연락처 카드 · 문의 폼)
├── activities.html                # 전체 즐길거리 목록
├── style-auto.html / style-glamping.html
│   └── style-backpacking.html / style-deck.html      # 캠프 스타일 상세 4종
├── act-canoe.html / act-trekking.html
│   └── act-campfire.html / act-stargazing.html       # 즐길거리 상세 4종
├── news-reservation.html / news-story.html / news-review.html   # 소식 & 리뷰 상세
├── styles.css                     # 메인·공통 스타일 (디자인 토큰 포함)
├── detail.css                     # 상세·서브 페이지 스타일
└── assets/
    ├── elements/                  # 이미지 (WebP 최적화)
    └── fonts/                     # self-hosted 폰트 (Pretendard · 고운바탕 · Caveat)
```

## ⚠️ 데모 한계 (참고)

- 백엔드가 없어 **예약 · 문의**는 프론트엔드 데모입니다. 입력값이 서버로 전송·저장되지 않고, 신청 시 **확인 화면만** 표시됩니다.
- 실제 **결제 · 예약 확정 · 배송**은 이뤄지지 않습니다.
- 연락처 · 주소 · 요금 등(예: `033-000-0000`, 강원도 ○○군, 요금 표기)은 **데모용 예시값**입니다.
